
# Arduino LED Blinking Project

## About the Project
This is a beginner-level Arduino project created using Tinkercad.

The project demonstrates how to blink an LED using Arduino UNO.

## Components Required
- Arduino UNO
- LED
- 220 Ohm Resistor
- Jumper Wires

## Circuit Connection
- LED positive leg is connected to Arduino pin 13 through a resistor.
- LED negative leg is connected to GND.

## Working
1. Arduino sends a HIGH signal to pin 13.
2. LED turns ON for 1 second.
3. Arduino sends a LOW signal to pin 13.
4. LED turns OFF for 1 second.
5. This process repeats continuously.

## Arduino Code
The code is available in `LED_Blink.ino`.
